Fælles*

* Danish for “in common” — it is also how we work.

We are a Danish cooperative of software, data and machine learning engineers. We build small, useful tools together — and we think how you build something matters as much as what you build.

What holds us together

Ethical engineering

We build things we can stand behind: no dark patterns, no tracking we wouldn't accept ourselves, no data we wouldn't hand over if asked.

Code-driven

Infrastructure, deploys, reviews — if it happens twice, it becomes code. Everything we run is declared, versioned and reproducible.

Work–life balance

Sane hours, sustainable pace, no hero culture. Good tools are built by people who are well — this is a side-project collective, and we like it that way.
