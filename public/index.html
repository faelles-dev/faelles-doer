FAELLES

$ whoami → a Danish software cooperative

We are a cooperative of software, data and machine learning engineers. We build small, useful tools together — and we think how you build something matters as much as what you build.

what holds us together

ethical engineering

We build things we can stand behind: no dark patterns, no tracking we wouldn't accept ourselves, no data we wouldn't hand over if asked.

code-driven

Infrastructure, deploys, reviews — if it happens twice, it becomes code. Everything we run is declared, versioned and reproducible.

european by design

We host on European infrastructure and use European software where it exists. GDPR is a floor, not a ceiling — our data stays where our users are.

work–life balance

Sane hours, sustainable pace, no hero culture. Good tools are built by people who are well — this is a side-project collective, and we like it that way.
